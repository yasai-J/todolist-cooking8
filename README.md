# MY LITTLE DAYS

GitHub Pages向けのPWAです。**すべてのファイルをリポジトリのルート階層に置いてください。** assets等のサブフォルダは使用していません。

## 公開方法
1. ZIPを展開し、中のファイルをGitHubリポジトリの最上位にアップロード。
2. Settings → Pages → Deploy from a branch → main / root を選択。
3. 公開URLをiPhoneのSafariで開き、共有 → ホーム画面に追加。
4. 初回はオンラインで開いてキャッシュを作成してください。

## データ
- タスク・気分・進捗はブラウザのlocalStorageに自動保存。
- JSON書き出し／読み込みに対応。読み込みは既存データを上書きします。
- ブラウザのサイトデータを消すと端末内データも消えるため、JSONバックアップを保管してください。

## タスク仕様
- Daily Routine：曜日指定。今日該当するタスクのみ表示し、日ごとに完了状態を記録。
- Weekly Routine：曜日指定なし。週内に1回完了すれば達成、週が変わると未完了に戻ります。
- Deadline：期限日を表示。期限超過後も未完了なら表示を継続。
- Wish List：期限なし。完了後もHOMEに取り消し線付きで残ります。
- 完了タスクはチェック後もHOMEに残ります。タスク名の長押し、または編集メニューからHOME非表示を選ぶとアーカイブへ移動します。
- アーカイブからHOMEへ戻すこと、タスクごとの完全削除ができます。
- ドラッグハンドルを長押しして、同じカテゴリー内のタスクを並べ替えられます。
- 今日の達成率は当日のDaily Routineのみで算出。

## メモ
- 気分の6段階イラストは個別素材を利用し、選択時に色別ボックス背景は付けません。
- レシピ一覧はオムライス、カレー、パスタ、ハンバーグ、グラタン、サンドイッチ、パンケーキ、パフェ、サラダ、うどん、ラーメン、丼もの、おにぎりを収録。
- 端末に存在するイラスト素材のうち、このパッケージに含まれていないものは表示されません。PNGの個別素材は同じ階層に追加してください。


## レシピ解放
- 初期レシピ：おにぎり・サンドイッチ・パンケーキの3種類。
- 月間達成率60%で4種類、80%で7種類、90%で10種類、100%ですべてのレシピを解放します。

## レシピイラスト
レシピイラスト1（7枚）とレシピイラスト2（5枚）、合計12枚を収録。左右のペア画像を「もうすぐ完成」「完成」に分割し、80〜99%と100%の進捗表示に使用します。レシピ一覧には完成イラストを表示します。

## 2026-11-03 追加素材
- `chef_base.png`: 基本のシェフ
- `chef_cut.png`: 野菜をカットするシェフ
- `chef_fry.png`: フライパンで炒めるシェフ
ホーム画面のシェフは基本デザインで固定し、テーブル上の料理イラストを達成率に応じて切り替えます。達成率0%では空のお皿を表示します。


### 料理進行イラストの割り当て
達成率に応じて、既存の料理中イラストを段階的に表示します。
- 準備前：chef_base.png
- 準備中：chef_cut.png
- 調理開始：chef_fry.png
- 仕上げ中：mascot_cooking_base.png
- もうすぐ完成：mascot_cooking_cut.png
- 完成：chef_base.png

専用イラストがない段階も既存素材を使い、基本画像だけに固定しない構成です。
